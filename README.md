## Exercícios

Os exercícios usam somente os conteúdos permitidos no enunciado: `MaterialApp`, `Scaffold`, `AppBar`, widgets de layout básicos, `TextField`, controllers, `ElevatedButton`, conversões, `if/else` e `setState()`.
